# Подбор смартфона с помощью машинного обучения

## Запуск
```
pip install -r requirements.txt
python main.py                      # приложение
python -m src.ml.experiments --grid # эксперименты в консоли (сравнение моделей, GridSearch)
```

## Конвейер
1. **Данные** — `data/phones_seed.csv` (287 моделей) собирается из трёх источников:
   ```
   python tools/scrape_telegram.py   # посты t.me/ishopper и t.me/polzaSKIDKI → data/sources/*.json
   python tools/merge_sources.py     # слияние → data/phones_seed.csv
   ```
   За основу берётся база августа 2026 (`data/sources/base_aug2026.csv`, все 211 моделей остаются).
   Характеристики из постов (`ishopper_specs.csv`, `extra_specs.csv`) заменяют старые значения и добавляют
   новые модели. Цена — медиана цен из обоих каналов за 06.09–05.11.2026 (без пошлины), иначе последняя
   цена из каналов, иначе августовская оценка; источник — в `price_source`.
   Автономность `active_h` (часы активной работы) и `standby_d` (дни ожидания) рассчитывает оценочная
   модель `estimate_autonomy` в `src/db.py` (по ёмкости, экрану, частоте, чипу и году) — это не замер.
   Проверка и очистка — функции курса `check_data_quality`, `drop_invalid`, `handle_missing`.
2. **Метки** телефонов `0 бюджетный / 1 средний / 2 флагман` — взвешенный скоринг перцентилей (`src/ml/labeling.py`).
3. **Веса признаков** (`src/ml/features.py`) — `StandardScalerCustom` + экспертные веса, ослабленные
   по mutual information с меткой и по корреляциям, чтобы признаки не «перетягивали» друг друга при кластеризации.
4. **Кластеризация** (`src/ml/clustering.py`) — KMeans k-means++, k по силуэту, метод локтя,
   сравнение с Agglomerative и DBSCAN, дендрограмма, автоматические названия кластеров.
5. **Опрос → нейросеть** (`src/ml/classifier.py`) — анкета + признаки кластеров → `MLPClassifier`
   (64-32, ReLU, Adam, early stopping) → класс [0,1,2]. Обучение на 6000 синтетических анкет
   (у «человека» скрытые приоритеты с шумом) + отзывы пользователя из БД.
6. **Ансамбли** (`src/ml/ensemble.py`) — `MajorityVoteClassifier` из `ens.py`, Bagging, AdaBoost, LogReg, Tree, KNN.
7. **Рекомендация** (`src/ml/recommender.py`) — полезность телефона для анкеты + вероятность класса + бонус кластера.
8. **Цены** (`src/providers/`) — API продавцов Яндекс Маркета, Ozon, Wildberries и Avito по ключам из `.env` (см. `.env.example`).

## Интерфейс
- **Простой режим** — пресеты «для чего телефон», бюджет, 4 ползунка, результат карточками с картинками.
- **Про-режим** (переключатель справа вверху) — 9 ползунков и все требования, таблица топ-10, «Почему он?»
  (вклад признаков), аналитика ML, а также «Дуэль», игра «Угадай класс» и «Песочница модели» (k, слои, анкеты).
- **Похожие** — у карточки, строки результата и каталога: по всем параметрам, камере, автономности,
  производительности, экрану, цене или «похожее, но дешевле».
- **Картинки** — рисуются по характеристикам (`src/ui/phone_art.py`); своё фото можно положить в
  `PhonePicker_data/images/<модель>.png` (или `data/../images` при запуске из исходников).

Учебные файлы курса: `src/data_loader.py`, `src/preprocess.py` (используются), `reference/` (исходные примеры).

## Сборка exe
```
python build_exe.py                  # всё сам: зависимости → чистая база → обучение → exe
python build_exe.py --skip-install --no-experiments --run   # быстрее и сразу запустить
```
Готовый файл — `dist/PhonePicker.exe` (БД, датасет и обученные модели внутри). При первом запуске рядом с exe создаётся папка `PhonePicker_data` с базой, моделями и `.env`; если рядом писать нельзя — `%LOCALAPPDATA%\PhonePicker`.
